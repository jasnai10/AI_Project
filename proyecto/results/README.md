# Resultados

Esta sección contiene los archivos generados durante la evaluación y comparación de los modelos.

La estructura de esta carpeta es:

```text
results/
├── metrics.csv
├── plots/
└── model_comparison.txt
```

* **`metrics.csv`**: tabla comparativa de las métricas obtenidas por cada modelo.
* **`plots/`**: gráficos generados durante el análisis y evaluación.
* **`model_comparison.txt`**: resumen de los resultados y comparación de los modelos.
