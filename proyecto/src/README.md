# Código fuente

Esta sección contiene los módulos utilizados para el procesamiento de los datos, la implementación de los modelos y la evaluación de los resultados.

La estructura de esta carpeta es:

```text
src/
├── preprocessing.py
├── models.py
└── evaluation.py
```

* **`preprocessing.py`**: funciones para la preparación y procesamiento de los datos.
* **`models.py`**: implementación de los modelos utilizados en el proyecto.
* **`evaluation.py`**: funciones para el cálculo de métricas y la evaluación de los modelos.
